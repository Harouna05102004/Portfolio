Hébergement Web mutualisé & passage en HTTPS

Contexte

La société WebHost PME souhaite proposer une offre d'hébergement mutualisé : un serveur doit héberger plusieurs applications clientes indépendantes. Objectif du TP : installer Apache, créer un VirtualHost et sécuriser le site en HTTPS avec un certificat auto-signé.

Environnement : machine virtuelle Debian 12 sous VirtualBox (IP 172.20.10.3).

Étape 1 — Installation d'Apache

Connexion SSH à la VM, puis passage en super-utilisateur et installation du serveur web.

  • Connexion : ssh harouna@172.20.10.3 (clé bloquée ? ssh-keygen -R 172.20.10.3)
  • Super-utilisateur : su -
  • Mise à jour et installation : apt update puis apt install apache2
  • Vérification du service : systemctl status apache2 → active (running)
Page par défaut dans /var/www/html, accessible via http://172.20.10.3 (« Apache2 Debian Default Page »).

Étape 2 — Activation des modules SSL

Activation du chiffrement SSL/TLS et de la réécriture pour la redirection HTTP → HTTPS.

  • a2enmod ssl — active le module SSL
  • a2enmod rewrite — active la réécriture d'URL
  • systemctl restart apache2 — applique la configuration
  • Vérification : a2query -m ssl → ssl (enabled by site administrator)

Étape 3 — Certificat auto-signé SSL/TLS

Génération d'un certificat auto-signé valable 10 ans (clé RSA 4096 bits, signature SHA-512).

openssl req -newkey rsa:4096 -x509 -sha512 -out mycert.pem -keyout mykey.key -days 3650
  • Certificat public : /etc/ssl/certs/mycert.pem
  • Clé privée : /etc/ssl/private/mykey.key
  • Sécurisation des droits : chmod 600 /etc/ssl/private/mykey.key et chown root:root /etc/ssl/private/mykey.key

Étape 4 — Fichier de configuration VirtualHost

Création du fichier /etc/apache2/sites-available/mon-site.conf avec deux blocs : un bloc HTTP (port 80) qui redirige tout le trafic vers HTTPS, et un bloc HTTPS (port 443) qui assure la liaison sécurisée.

<VirtualHost *:80> ServerName 172.20.10.3 Redirect permanent / https://172.20.10.3/ </VirtualHost> <VirtualHost *:443> ServerName 172.20.10.3 DocumentRoot /var/www/html SSLEngine on SSLCertificateFile /etc/ssl/certs/mycert.pem SSLCertificateKeyFile /etc/ssl/private/mykey.key SSLProtocol all -SSLv3 -TLSv1 -TLSv1.1 SSLCipherSuite HIGH:!aNULL:!MD5 <Directory /var/www/html> Options Indexes FollowSymLinks AllowOverride All Require all granted </Directory> ErrorLog ${APACHE_LOG_DIR}/mon-site_error.log CustomLog ${APACHE_LOG_DIR}/mon-site_access.log combined </VirtualHost>

Étape 5 — Activation du site et tests

  • Activation du site : a2ensite mon-site.conf
  • Test de la syntaxe : apache2ctl configtest → Syntax OK
  • Redémarrage : systemctl restart apache2
  • Côté client Windows : ajout du domaine dans C:\Windows\System32\drivers\etc\hosts et import du certificat SSL.
Résultat : le site bascule automatiquement de HTTP (port 80) vers HTTPS (port 443) avec la liaison SSL/TLS active.
